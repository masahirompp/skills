# init の手順

新規プロジェクト(グリーンフィールド)のセットアップ。

1. **前提確認**: git リポジトリであること。既存の README や構想メモがあれば、最初の仕様詰めの入力候補として提示し、扱いを人間に確認する
2. **`docs/adr/`・`GLOSSARY.md`・`docs/PRODUCT.md` は作らない。** 空の器を先に置くと、仕様を詰める前に推測で埋められ、仕様が汚染される。`docs/adr/` と `GLOSSARY.md` は最初の仕様詰めで、最初の ADR・用語と一緒に作り、PRODUCT.md はその結果から合成する
3. **層のパスを確定し、CLAUDE.md に規約ブロックを追記する**(下記テンプレート)。既定(使い捨て層 = `src/` とテストコード)で足りるなら聞かずに進む。monorepo や `src/` を使わない構成など既定が合わないときだけ、削除対象パスを人間と合意する
4. **コミット**: 作成・変更したファイルをコミットする
5. **報告**: rewrite(最初の仕様詰めと実装)に進むことを提案する。未作成の docs は作り忘れと区別がつかないので、意図的に作らなかったことと理由を報告に含める

GitHub のラベルやマイルストーンは作らない。

## CLAUDE.md 追記ブロック

CLAUDE.md の末尾に追記する(CLAUDE.md が無く AGENTS.md があればそちらに、どちらも無ければ CLAUDE.md を作成)。層の定義のパスは確定した実パスに置き換える。文言はプロジェクトに合わせて調整してよいが、3層自律判断・学びの反映と完了報告・ADR の基準は省略しない。セッションを跨いで確実に効かせる必要があり、それを保証できるのは毎セッション読まれる CLAUDE.md だけ。

```markdown
## サイクル型リライト開発(cycle-rewrite)

このプロジェクトは、コードをいつでもゼロから作り直せるように、仕様と学びを docs に積み上げて開発する。学びの反映・完了報告・作り直しは cycle-rewrite スキルに従う。

### 層の定義

- 永続層: `docs/`(PRODUCT.md、adr/)、`GLOSSARY.md`、`.claude/skills/`、CLAUDE.md — 厳格に維持する
- 使い捨て層: `src/` とテストコード — 作り直しで全削除する。品質は「動けばOK」

作り直しの削除対象はこの定義を正とする。作り直しても残すコードは、この定義から外す。

**使い捨て層の削除は、人間が作り直しを頼んだときだけ行う。** `git tag rewrite-YYYY-MM-DD` を打ってから削除する。

### AI の自律判断(3層)

1. **内部設計の変更**(外から見える挙動が変わらない): 自律で進めてよい。判断内容はコミットメッセージに書く。
2. **観測可能な挙動・仕様の変更**: docs(PRODUCT.md・ADR・GLOSSARY.md)に定めた挙動を変えるなら、人間へのエスカレーション必須。質問は「挙動 A と挙動 B のどちらが欲しいか」というドメイン語の二択で行う。コードの理解を要求する質問はしない。docs に定めの無い挙動は、暫定の挙動を選んで進め、採った案をコミットメッセージに書き、完了報告で選択肢と一緒に示す(確定は人間が行う)。
3. **不可逆・外部影響**(課金、外部 API 契約、本番データ、公開等): 常に同期エスカレーション。例外なし。

### 学びの反映と完了報告

実装・確認中に得た学びは、issue を経由せず、分かった時点で docs に直接書いてコミットする。ライブラリや環境のハマりは `.claude/skills/` に、進め方のルールは CLAUDE.md に、聞かずに書く。

仕様(要件と用語)・暫定で採った挙動・ADR は人間が決める。作業を終えて報告するときに、1件ずつドメイン語の選択肢で示し、いま決めるか issue に残すかを聞く。決まったものは docs に反映し、issue に残すと言われたものだけ起票する。調べただけの短いやり取りでも、応答を終える前に行う。

### ADR の基準

ADR にするのは、「**コードを作り直しても覆らないか**」に当てはまる判断だけ。捨てる予定のコードに紐づく実装レベルの判断は ADR にしない(コミットメッセージでよい)。

### 作り直す前のコードの参照

作り直す前のコードを作業ツリーに置かない。参照が必要なら `git show <タグ>:src/...` か、作業ツリー外への `git worktree` を使う。
```
