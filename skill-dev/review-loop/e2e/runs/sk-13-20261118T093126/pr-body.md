## 背景

`security-review` が、この PR で削除した `.env` の中身を確かめようとして、権限の設定で拒否され、試行が止まった。PR #12 で止めなくなったのは複合コマンドの一部が拒否された場合だけで、`.env` を単独で読む呼び出しは今も試行を止める。

## 変更

- `--perspective <スキル名と引数>`(繰り返せる): 1つでも渡すと、`PERSPECTIVES` の代わりにそれだけを使う。既定と違う観点(スキル名が同じで引数だけ違うものを含む)で回した試行は、状態コメントの表に渡した観点が載る
- `--instruct <スキル名>=<指示>`(繰り返せる): その観点のレビュー役のシステムプロンプトに指示を足す。判定役の入力にも添える
- 観点にないスキル名への指示、空の観点、形の誤りは終了コード2
- SKILL.md: 利用者の指示があるときだけ付け、以後の反復でも毎回同じものを付ける。権限の拒否で止まったときは、自分では付けずに利用者に提案する

```sh
python3 .../review_loop.py iterate /path/to/wt \
  --instruct 'security-review=この PR で削除した .env の中身は確かめない'
```
