レビューで確かめたのは2点で、どちらも判定役(judge)が `result` の行を複数出したときに起きます。今回の変更で、判定役の `result` の行もすべてつなぐようになったことが原因です。

この2点のほかに、次のものは指摘として証明できませんでした。
- 既存のテスト(`TMPDIR=$PWD/scratch/tmp python3 skill-dev/review-loop/test.py`)は「全て成功」でした。
- 判定役が設定のルール以外で拒否されて実行を続ける場合も試しました。1.6 秒で `failed: permission_denied: judge` になり、子プロセスも残りませんでした。意図どおりです。
- `modelUsage` が本当にセッションの累計かどうかは、本物の claude を動かさないと確かめられないので、検証していません。

## 指摘1: 前置きでコードフェンスを開いた判定のあとに短い `result` の行が続くと、閉じフェンスと余計な文が判定に残る

**実行したコマンド**

`scratch/wrap/claude` は判定役のときだけ次の2行の `result` を出し、それ以外は元の偽の claude に渡します。
1. `"以下が判定です。\n\n```markdown\n## 指摘 …\n## 競合\n\nなし\n```"`
2. `"判定は前のメッセージのとおりです。"`

`scratch/harness.py` は `test.py` の準備の部分を読み込んで、`X_JUDGE=fence_then_short` で `iterate` を1回実行します。

```
TMPDIR=$PWD/scratch/tmp python3 scratch/harness.py
```

**出力**
```
=== X_JUDGE=fence_then_short rc=0
--- stdout ---
## 指摘

### F1: s
- 観点: code-review
- 場所: a.txt:1
- 影響: 中。r

## 競合

なし
```

判定は前のメッセージのとおりです。
--- end ---
```

**出るべきだった出力**

`run_judge` には「前置きでコードフェンスを開いていたときだけ、末尾の閉じフェンスも落とす」という処理があります(`skills/review-loop/scripts/review_loop.py:800-805`)。この意図に沿うなら、結果は `なし` で終わり、閉じフェンスの ```` ``` ```` も `判定は前のメッセージのとおりです。` も含まないはずでした。

実際には、つないだテキストの末尾が閉じフェンスではなくなるため、正規表現 `\n```\s*$` が一致しません。その結果、フェンスの閉じと途中経過の文が `verdict.md` と標準出力に残ります。

## 指摘2: 判定役が判定を2回出すと、`## 指摘` と `## 競合` が重なった判定がそのまま成功する

**実行したコマンド**

上と同じハーネスで、`X_JUDGE=repeat` の場合です。同じ判定の `result` を2行出します。

```
TMPDIR=$PWD/scratch/tmp python3 scratch/harness.py
```

**出力**
```
=== X_JUDGE=repeat rc=0
--- stdout ---
## 指摘

### F1: s
- 観点: code-review
- 場所: a.txt:1
- 影響: 中。r

## 競合

なし

## 指摘

### F1: s
- 観点: code-review
- 場所: a.txt:1
- 影響: 中。r

## 競合

なし
--- end ---
```

**出るべきだった出力**

判定は、決めた形(`## 指摘` と `## 競合` が1つずつ)に揃った1つだけであるべきでした。実際には F1 が2回入った判定が終了コード0で返ります。見出しの確認(`re.search` で各見出しが1つ以上あるか)は、見出しが重なっていても通ってしまいます。

一方で、判定役が同じ判定を2回出す場面が本物の claude でどれだけ起きるかは、確かめていません。指摘1より確度は低いです。判定役は普段バックグラウンドのサブエージェントを使いません。このため、判定役の `result` の行は「最後の空でない行を採る」か「見出しが重なったら `no_output` にする」のどちらかに絞る、という選択肢も考えられます。

確かめるのに使ったファイルは `scratch/wrap/claude` と `scratch/harness.py` にあり、一時ディレクトリは片付けてあります。
