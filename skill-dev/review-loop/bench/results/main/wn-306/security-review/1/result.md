`src/ops/app.ts` の `openNote` と `openWait` で、起動された行を断る判定(`isSpawned`)が外されました。ところが、カーソルを置く道のうち3つが `selectableOrder` を通っていません。

このため、たとえば次の順で、起動された行のメモ欄が開けます。

1. attach したあとで、そのセッションが起動された行と分かる。
2. attach 先でメモのキーを押す。

待ち先は `validWaits` が起動元を除くので保存されませんが、編集の画面は開きます。操作するのは手元の利用者本人だけで信頼の境界をまたがないため、脆弱性には数えていません。ただ「起動された行にはメモも待ち先も結ばない」という仕様からは外れます。直し方は次のどちらかです。

- `openNote` と `openWait` の判定を残す。
- 上の3か所でもカーソルを `selectableOrder` で確かめる。
