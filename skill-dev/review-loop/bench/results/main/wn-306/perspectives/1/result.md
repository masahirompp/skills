## 設計

- **選べるかの判定元が2つある:`src/screen/screen.ts:201` は `r.marker !== 'sub'`、`src/model/cursor.ts:3` は `node.spawned` で決めている。**
  - 今は `app.ts:447` の写し方で一致していますが、表示用の印を選べるかの判定に流用している形です。
  - 例えば `(sub)` と `(tty)` の両方を出すように印を変えると、通し番号とカーソルの動きが黙ってずれます。
  - `ScreenRow` に `selectable` などの明示的な欄を持たせるほうが壊れにくいです。

- **`src/model/cursor.ts:3` の `isSpawned` が、毎回すべての区切りのすべての行をなめる。**
  - `selectableOrder` は `order.filter` の中でこれを呼ぶので、計算量は O(n²) です。`↑` `↓` のたびに呼ばれます。
  - 行が数十であれば問題になりません。気になるなら、`Layout` に `spawned` の Set を持たせれば済みます。優先度は低いです。
