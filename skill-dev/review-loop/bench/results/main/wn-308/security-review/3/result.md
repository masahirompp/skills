差分の範囲は `lib/tmux/tmux.ts:340` だけです。ここでは、作業台の `status-format[0]` の書式の末尾に固定の文字列 ` · ^Q%% split │ · ^Q" split ─ · ^Qc window` を足しています。

- 足した文字列はコードに直接書いた定数です。利用者由来の値(セッション名、依頼、ウィンドウ名など)は入っておらず、書式インジェクションやコマンドインジェクションの新しい入口はできていません。
- `%%` は strftime を通るときに `%` を出すための書き方です。tmux の書式の解釈や、シェルの実行には関わりません。
- `#{@wn_name}` と `#{W:...#{window_name}...}` は、この変更より前からある部分です。この差分では扱いを変えていません。
- そのほかの変更は、ドキュメント(`docs/PRODUCT.md`、`docs/lib/tmux.md`、`.claude/skills/working-with-tmux/SKILL.md`)と e2e テストの期待値だけです。どちらも除外の対象です。
