5. `lib/tmux/tmux.ts:340`: ステータス行に、East Asian Width が Ambiguous の `│`(U+2502)と `─`(U+2500)を足した。tmux はこれを幅1と数えるが、曖昧な幅を全角にする端末では幅2で描かれ、ステータス行の幅の計算がずれる。

   Failure scenario: 利用者は日本語の環境にいる。iTerm2 などで「曖昧な幅の文字を全角にする」を有効にしていると、`│` と `─` が2桁ずつ描かれる。tmux の考える行より2桁長くなるので、右端の `window` が折り返すか欠け、カーソルの位置もずれる。`·` も同じ性質だが、この差分で曖昧な幅の文字が3つから5つに増えた。境目の向きは `left/right`、`top/bottom` のように ASCII でも示せる。

6. `lib/tmux/tmux.ts:340`: キーの説明の `^Q` を文字列に直に書いていて、同じ関数で設定している prefix `C-q` から作っていない。src 側の ATTACH_KEYS_HELP はキーの定義から作っているので、作り方が揃っていない。
