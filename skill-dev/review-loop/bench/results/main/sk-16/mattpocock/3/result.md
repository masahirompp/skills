**(c) 実装されているが、誤っていそうなもの**
1. **「実行では示せない」が、仕様にない例外になっている。**
   - 仕様は「再現しなければ採らない」です。SKILL.md:103 は、実行で示せない指摘をコードで追って採ってよいとしています。
   - :126 が継続の理由から外すのは「差分の外」と「試したが起きなかった」の2つだけで、この扱いで採った指摘は外れません。

   - このリポジトリの PR は SKILL.md やプロンプトを変えるものが中心で、指摘の多くがこの扱いに入ります。そのため、動機にある「反復が伸びる」がこの種類の PR では解消しません。
2. **再レビューを省く条件の「どの修正も」が、何を指すかあいまい。**

   - 「修正が大きく、再現が確かめた範囲を超えて」には判断の基準がなく、緩くも読めます。
3. **差分の外にある横展開の候補が、どこにも残らない。**
   - 横展開の候補には範囲の欄がありません。
   - そのため、差分の外の候補は終了時の報告にも、issue にするか尋ねる対象にも入りません。
