## 確認した範囲

  - 足した文字列に、利用者や外部から来る値は入っていません。`%%` は strftime で `%` を出すための書き方で、tmux の書式としての意味は変わりません。
  - 利用者が決められる値(`#{@wn_name}`、`#{window_name}`)は、この変更より前からある部分で、今回は手を入れていません。そのためレビューの対象から外しました。

- **`docs/PRODUCT.md`、`docs/lib/tmux.md`、`.claude/skills/working-with-tmux/SKILL.md`**: ドキュメントだけの変更です(除外の条件に当たります)。
