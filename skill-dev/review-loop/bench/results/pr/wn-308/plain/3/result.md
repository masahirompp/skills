## 問題ないと確かめた点

- **`%%` の書き方(`lib/tmux/tmux.ts:339-340`)は正しいです。** tmux は書式を展開する前の文字列に strftime をかけます。今回の `%%` は `#{...}` の外にあるので、strftime を1回通って `%` になります。e2e の `\^Q%` が通っていることとも合います。
  - 補足:`#{W:...}` の中に `%` を書くと、入れ子の展開でもう一度 strftime を通ります。skill の追記(`SKILL.md:41`)に「`#{...}` の外では」と範囲を添えておくと、後で中に動かしたときの罠を防げます。
- **`^Q%` はちゃんと分割として効きます。** 全体の割り当てに `bind -n C-q switch-client -T wnq` があります(`tmux.ts:128`)。それでも作業台のセッションは prefix が `C-q` で、tmux では prefix の判定が root の表より先に行われます。そのため `%` は prefix の表の既定の割り当て(split-window)に届きます。
- **`PRODUCT.md:442` の図は、ほかの行と同じ75桁に揃っています。** 右の画面に入るのは34桁で、`^` で切れる見え方とも合います。
- **`docs/lib/tmux.md` の契約も更新されています。** `lib/` を変えたときの docs の手当ては済んでいます(言葉の使い方は上の指摘のとおりです)。
