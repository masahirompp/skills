- **問題なし: `%%` の書き方は利用者由来の名前に影響しない** `lib/tmux/tmux.ts:339-340`。tmux 3.8 の使い捨てサーバで試しました。`@wn_name` に `100%d name`、ウィンドウ名に `w%Hx` を入れて展開しても、`100%d name  0:w%Hx*  · ^Q% split` となりました。strftime は書式の文字列にだけかかり、`#{...}` で差し込む値にはかかりません。利用者の文字列を `%%` にする必要はありません。
