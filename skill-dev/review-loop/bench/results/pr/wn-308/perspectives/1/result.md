## 確かめて問題がなかった点

- **`%%` の扱い**: tmux は書式の文字列だけに strftime を通し、`@wn_name` などの値には通しません。そのため、`%%` が要るのはここで足した文字の部分だけで、利用者由来の値は今までどおり `escapeFormat` で足ります。
- **区切りの空白**: 窓の一覧(`#{W:…}`)の各項目は空白で終わるので、そのあとの ` · ` と合わせて `0:zsh*  · ^Q%` の2つの空白になります。テストの ` {2}·` と docs の例とも合っています。
- **docs の画面の例の幅**:
  - 「採らなかった形」の例は、左が35桁、空白1桁、右の残りの24桁で、ちょうど60桁です。右寄せで左から欠けたときの見え方と一致しており、手で書いた例ではなさそうです。
  - 442行目の図も、元の行と同じ34桁に収まっています。
- **`GUIDE` の画面**: セッション名だけを出す分岐はそのままで、「作業台がないときはセッション名だけ」という仕様と合っています。
