一覧の n で、候補の先頭をカーソルのあるセッションのリポジトリにする

## 何を変えるか

一覧で `n` を押したときの作業ディレクトリの候補の先頭を、カーソルのあるセッションのリポジトリ(worktree なら元のリポジトリ)にする。`ctrl+q ctrl+n` と同じ扱い。行がないときは従来どおり、whatnext を起動したディレクトリが先頭になる。

利用者の判断(2026-11-02)。同じリポジトリで別の作業を始めることが多いため。

## 変更

- `src/ops/app.ts`: 一覧の `n` で `openNew(undefined, sid)` を呼ぶ
- `docs/PRODUCT.md`: `n` の候補の順と理由、受け入れシナリオ 8 に1文
- `test/e2e/ops.test.ts`: カーソルを別リポジトリの行に置いて `n` を押すと、そのリポジトリが先頭になるテスト

build、`npm run check`、単体テスト、`test/e2e/ops.test.ts`
