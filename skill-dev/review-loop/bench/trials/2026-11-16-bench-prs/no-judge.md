# 判定役を通さず、レビュー役の出力を俯瞰の役に直接渡す試し(2026-11-17)

判定役を無くして、その仕事を俯瞰の役に寄せられるかを、`README.md` の2題材の反復2で1回ずつ確かめた。スクリプトは変えていない。

## やったこと

- 入力: 反復2の、判定役への入力(`judge-input.md`。レビュー役3つの出力を、役の名前の区切りでつないだもの)。判定(`verdict.md`)は渡さない
- ほかの材料は、俯瞰の役と同じ(PR の差分と本文、修正前後のファイル、`history/` に反復1の判定と修正の差分)。判定役を無くした形では、`history/` に入るのは前回の俯瞰の出力になるはずで、ここは本番の形と違う
- 依頼文: `references/overview.md` の依頼文に、次を足した
  - 手順0: 3つの出力を突き合わせる。同じ問題は1件にまとめ、挙げた役を残す。根拠を読むか動かして確かめ、当たらない指摘は外して理由を書く。役どうしの食い違いを裁く。以前に採らなかった指摘は、覆す事情があるかを見る
  - 出力の先頭に、まとめた指摘の表(番号、要約、場所、挙げた役、影響、起きやすさ、範囲、扱い)。外した指摘も載せる
  - 字数の目安を、表を除いて2000〜4000字に広げた
- モデルは Opus 5.5。文脈を引き継がないサブエージェント
- 突き合わせは、親(判定と俯瞰の結果を両方読んでいる)が1人で行った

## 結果

| | sk-12 反復2 | wn-313 反復2 |
|---|---|---|
| 判定の指摘 → まとめた指摘 | 16件 → 14件 | 13件 → 13件 |
| 判定にあって、表に無い指摘 | 0件 | 0件 |
| 挙げた役が、判定の「観点」欄と一致 | 14件の全て | 13件の全て |
| 当たらないとして外した | 2件(判定では低が2件) | 2件(判定では低が1件、なしが1件) |
| 影響の段階が判定と違う | 1件(判定は中、こちらは低) | 2件(判定は中と低、こちらは低となし) |
| PR の方針 | 範囲を変える(分ける) | このまま進める |
| 所要、トークン、ツールの回数 | 約6.4分、11.5万、18回 | 約6.4分、11.3万、30回 |

- 落とした指摘は無かった。bench の正解に当たる指摘(sk-12 の S12-1 と S12-4、wn-313 の W313-6)も残り、どれも規則に入った
- sk-12 の PR の方針は、判定を経た俯瞰の役と同じ結論、同じ根拠(拒否のイベントの形が、本物で未観測)だった。wn-313 の反復2は、判定を経た俯瞰を行っていないので、比べるものが無い
- 判定役より踏み込んだ点: 根拠を実行で確かめた。wn-313 では、判定役が「シグナルで終わる場合は `res.signal` で見分けられるので、以前の理由の一部を覆す」とした指摘を、本物の tmux で動かして、SIGTERM と SIGHUP では終了コード 1 で終わり見分けられないと確かめ、覆さないと裁いた
- 判定役より粗くなった点:
  - 指摘ごとの記録が、表の1行になる。判定にある根拠の行番号の列挙、再現の手順、横展開の候補は、規則に入った指摘の分しか残らない
  - sk-12 で、判定が別の指摘として挙げたテストの不備(偽の claude の `denyconfignoid` の形)が、元の指摘に畳まれ、「以前に採らなかった」の扱いになった。判定役は「テストは直すべき」と書いていた

## 費用

同じ反復の、今の形との比較。

| | 今の形(判定役+俯瞰の役) | 1つにした形 |
|---|---|---|
| sk-12 反復2 | 判定役 約3.4分・$0.97、俯瞰の役 約4.2分・8.9万トークン。計 約7.6分 | 約6.4分、11.5万トークン |
| wn-313 反復2 | 判定役 約2.9分・$0.92(俯瞰は行っていない) | 約6.4分、11.3万トークン |

- 俯瞰も行う反復では、所要は約1分(15%ほど)縮み、判定役の費用が丸ごと浮く代わりに、俯瞰の役の消費が3割ほど増える
- 俯瞰を省く反復では、判定役だけの今の形のほうが短い(約3分に対して約6.4分)
- 判定役の費用は金額、サブエージェントの消費はトークン数でしか取れておらず、同じ単位では比べていない

## 言えること、言えないこと

- 2題材、1回ずつ。俯瞰の役の判断は回によって割れることが分かっている(`../2026-11-16-policy-overview/`)ので、段階や方針の一致・不一致は、割れの範囲かどうかを見分けられない。言えるのは、この2回では指摘を落とさなかったことと、挙げた役の記録が保たれたこと
- 影響の段階は、付ける役によって変わった(3件)。片方だけなら落とす中以上の指摘の数えも、この段階に依存する。wn-313 反復2は、判定では「1つ目だけなら1件、2つ目だけなら1件」だが、こちらの段階では「1つ目だけなら0件、2つ目だけなら1件」になる
- 反復1(指摘が最も多く、`history/` が無い回)では試していない
- 判定役を無くすと、反復ごとの独立性(判定役に過去を渡さない)が無くなる。その影響は、この試しでは見ていない
- スクリプトの子として起動する形(権限の拒否の監視、トークンの集計、状態コメント)は試していない。サブエージェントとして起動した

出力の原文は残していない。wn-313 の内容は、別のリポジトリのものなので、要点だけを書いた。
