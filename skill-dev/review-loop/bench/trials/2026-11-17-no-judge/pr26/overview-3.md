## PR の方針への判断
**このまま進めてよいと考えます。** 判定役を外す、俯瞰を毎反復の必須にする、モデルを固定する、という方針の根拠を崩す指摘はありません。今回、再現させる対象にあたるのは実質 F1 だけです。

ただし、兆候が2つあります。
- 直す対象と終了の基準の文面が、3反復続けて中の穴を出しています。そのため、規則1は継ぎ当てをやめて、1か所の定義にまとめることを勧めます。
- 規則1の修正は文書なので「実行では確かめていない」になり、反復4が要ります。3回の目安を超えるので、回す前に利用者に報告し、判断を仰ぐ必要があります。その際、F3 の論点も材料として渡す価値があります。文書が中心の PR では、文書の修正のたびに、全ての役を回す反復が1回増える、という点です。

修正の順序:
1. 規則1(定義を1か所にまとめる。コミット1つ)
2. 規則4の文面と、F14・F15 の検査(再現なしで直すもの)
3. PR 本文(F8、F9 の理由)
4. 修正の差分のレビュー
5. 反復4を回すかを利用者に尋ねる
