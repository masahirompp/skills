# copy-cmd — 案内したコマンドをクリップボードに入れる

整形とコピーは `scripts/copy_cmd.py` が行う。エージェントの仕事は、どのコマンドをコピーするかを決めて、その文字列を手を加えずにスクリプトへ渡すことだけ。整形を自分でやらないのは、クォートやヒアドキュメントの中の `&&` や `\` を見誤ると、貼り付けたコマンドが壊れるため。

引数 `$ARGUMENTS` で動作が変わる。

| 引数 | 動作 |
| --- | --- |
| なし、またはヒント(例: `gh`、`2つ目`) | 会話からコマンドを抜き出して登録し、全コマンドをまとめてコピーする |
| `next` | 登録済みの次の1コマンドをコピーする |
| 数字 `N` | 登録済みの N 番目をコピーする(以後の `next` は N+1 番目から) |
| `all` | 登録済みの全コマンドをまとめてコピーし直す |

## 1. コマンドを抜き出す(引数なし・ヒントのとき)

直近のアシスタントの応答から見て、ユーザー自身に実行してほしいと案内したコマンドを探す。見つからなければ2〜3メッセージ前まで遡る。対象になるのは次のようなもの。

- `! gh auth login` のように、ユーザーに `!` 付きで打つよう勧めたコマンド
- 「次を実行してください」「ターミナルで叩いてください」と添えたコードブロック
- ユーザーが「どうやるの?」と聞き、答えとして示したコマンド

対象にしないもの: エージェント自身が Bash ツールで実行したコマンドと、その出力。説明のために引用しただけのコード(設定ファイルの中身、スクリプトの本文など)。

複数の候補があるときは、ヒントがあればそれに合うものを、なければ最も新しい案内を選ぶ。ひとつの案内が複数のコマンドやコードブロックに分かれているなら、案内された順にすべて含める。どれを指しているのか決めきれないときだけ、候補を挙げてユーザーに聞く。案内したコマンドが見当たらなければ、コピーせずにそう伝える。

抜き出した文字列は、`!`、`$ `、`\` の折り返し、コメント、コードフェンスを含めて、案内したときの見た目のまま渡す。整形はスクリプトが行う。スクリプトは1コマンドを1行にするが、ヒアドキュメント、改行を含むクォート、`for … done` や `if … fi` のような複合コマンドは、複数行のまま1コマンドとして扱う。

ただし、案内の中にコマンドの実行例として出力が混ざっている場合(`$ ls` の次の行に出力が続くなど)は、出力の行を除いてコマンドの行だけを渡す。スクリプトにはコマンドと出力を見分けられないため。

## 2. 登録してコピーする

区切り文字を引用符で囲んだヒアドキュメントで渡す(中の `$` や `` ` `` を展開させないため)。

```sh
python3 <skill-dir>/scripts/copy_cmd.py set <<'__COPY_CMD_END__'
<抜き出したコマンド>
__COPY_CMD_END__
```

`next` / `N` / `all` のときは、抜き出さずに登録済みのものを使う。

```sh
python3 <skill-dir>/scripts/copy_cmd.py next
python3 <skill-dir>/scripts/copy_cmd.py line 3
python3 <skill-dir>/scripts/copy_cmd.py all
```

登録はセッションごとに分かれる(スクリプトが環境変数 `CLAUDE_CODE_SESSION_ID` を読む)。この変数が無い環境では「セッション ID が分からない」で止まるので、会話ごとに決めた任意の文字列を `--session <ID>` で毎回同じように渡す。

ただし、前回の copy-cmd のあとに別のコマンドを新しく案内しているなら、`next` でも古い登録を使わず、手順1から抜き出し直して `set` してから `next` を実行する(1番目がコピーされる)。

`next` の前に、ユーザーが登録済みのコマンドを `!` で自分で実行した跡(`! cd ~/work/site` とその出力など)が会話にあれば、そこまでは済んだものとみなし、`next` の代わりに `line <済んだ最後の番号+1>` で続きをコピーする。同じコマンドをもう一度貼らせないため。

## 3. 報告する

スクリプトの出力をもとに、コピーした内容をコードブロックで示す。長い前置きはいらない。

- 複数のコマンドをまとめてコピーしたとき: 「1つずつなら `next`」と一言添える。`&&` でつながっていた行は行末に `&&` が残っているので、まとめて貼っても途中で失敗すればそこで止まる(`next` でコピーするときは `&&` を付けない)
- 1つだけコピーしたとき: 何番目か(`2/3` など)と、次があればその内容
- Claude Code のプロンプトで実行するなら、貼り付ける前に先頭へ `!` を付ける、と初回だけ添える

スクリプトがエラーで終わったら(コマンドが空、登録が無い、最後のコマンドまでコピー済みなど)、そのメッセージを伝える。
